Some final features and polish are going into Inkweld, along with the last preparations for the first beta release, 1.0.0-beta.1.

From the last few days:

- Scenes can be written as conversations, with each line in its own speech bubble ([#1627](https://github.com/bobbyquantum/inkweld/pull/1627)).
- Inkweld offers to install itself as an app from the browser ([#1626](https://github.com/bobbyquantum/inkweld/pull/1626)), so the Electron desktop app and the Android app are gone ([#1630](https://github.com/bobbyquantum/inkweld/pull/1630), [#1625](https://github.com/bobbyquantum/inkweld/pull/1625)).
- Cloud Sync downloads work again, and documents open from the tree in Firefox ([#1628](https://github.com/bobbyquantum/inkweld/pull/1628)).

You can try it at [inkweld.app](https://inkweld.app), or read the [source on GitHub](https://github.com/bobbyquantum/inkweld).
