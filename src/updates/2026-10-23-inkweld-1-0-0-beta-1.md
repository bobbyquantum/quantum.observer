So, the first beta of Inkweld 1.0 is out: [1.0.0-beta.1](https://github.com/bobbyquantum/inkweld/releases/tag/v1.0.0-beta.1).

I think it has the features it needs now. I could keep adding things forever (it’s still my favourite way to avoid finishing the book), but the betas are about testing and fixing bugs. I’ve taken the roadmap down too. If people start using it, I’d rather what they ask for decided what comes next than my list did.

What’s in it, roughly:

- An editor with scenes, notes, snapshots and comments. Scenes can also be written as conversations, one speech bubble per line.
- Worldbuilding: characters, places and anything else you want to keep track of, with relationships, timelines and maps.
- Templates for worldbuilding, tabletop RPGs and scripts. The tabletop one comes with a short illustrated adventure, *The Drowned Lantern*, if you want to see one filled in. Slop tier, so don’t expect to actually get much use out of it, and human-made replacements are welcome (as for all the demos). I’d like to have all human content for the demo projects by the time I mark this as beta complete.
- Publishing to EPUB, PDF, HTML, Markdown, or a small website.
- Three places to keep your work: just in your browser, in your own Dropbox, Google Drive or Nextcloud, or on an Inkweld server where you can write with other people in real time.
- AI is off unless you switch it on, both on the server and for yourself. The main use case is quick image generation for worldbuilding content, and reviewing for grammatical errors. There’s nothing for generating text within the app, and I’m not planning to add that. If you do want that, there’s MCP support.

The [release notes](https://github.com/bobbyquantum/inkweld/releases) have the full list.

From here on, the plan is that every release upgrades from any earlier one by itself, with no exporting and no starting again.

You can try it at [inkweld.app](https://inkweld.app), run it yourself with Docker (`ghcr.io/bobbyquantum/inkweld:beta`), or read the docs at [inkweld.org](https://inkweld.org).

One thing on inkweld.app: don’t pick a sync server there unless you’ve set one up somewhere and turned on the option that allows access from inkweld.app. And if you’re self-hosting, honestly, you might as well use the app your own server serves rather than the .app one.

If something breaks, and I guess something will, please [open an issue](https://github.com/bobbyquantum/inkweld/issues).
