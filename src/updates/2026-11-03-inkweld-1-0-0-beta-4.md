[1.0.0-beta.4](https://github.com/bobbyquantum/inkweld/releases/tag/v1.0.0-beta.4) is out, and it has something in it I haven’t had before: a pull request from someone else.

[pixo2000](https://github.com/pixo2000) wanted to write a story with some friends in Inkweld without managing another password, so they [asked for OpenID Connect sign-in](https://github.com/bobbyquantum/inkweld/issues/1711) and then [built it](https://github.com/bobbyquantum/inkweld/pull/1712). Thank you!

If you run your own server, you can now sign in through your own identity provider. I’ve tested it with [Pocket ID](https://pocket-id.org), which is what pixo2000 uses, and other OpenID Connect providers should work too, though ones that only accept `client_secret_basic` won’t yet. It’s new, so if you try it with yours, I’d like to hear how it goes.

There’s also an OIDC-only mode, which turns off passwords, passkeys, GitHub, Home Assistant sign-in and local registration, so your provider is the only way in. On a fresh server, the first person to sign in becomes the admin. If your server already has accounts, [read the docs](https://inkweld.org/docs/configuration/#openid-connect-oidc) before turning it on, because you can lock yourself out. All of this is off unless you turn it on.

Canvases got a lot of attention too:

- Over MCP, assistants can now read a canvas, draw on it, upload images and look at the result ([#1704](https://github.com/bobbyquantum/inkweld/pull/1704), [#1705](https://github.com/bobbyquantum/inkweld/pull/1705)).
- The same new options are there for people: the text dialog has font, style, size, line height and letter spacing, and a new Effects… dialog has shadows, blend modes, image fit, corner radius and text outlines ([#1705](https://github.com/bobbyquantum/inkweld/pull/1705)).
- SVG export wraps text where the canvas does, and keeps shadows and blend modes ([#1705](https://github.com/bobbyquantum/inkweld/pull/1705)).

And some fixes:

- Disabling or rejecting an account, resetting its password or recovering its passkey now disconnects any apps linked to it over MCP. Before, a linked assistant could keep working ([#1706](https://github.com/bobbyquantum/inkweld/pull/1706)). If you run your own server and use MCP, this one’s worth upgrading for.
- PDF export works offline, and exporting a PDF no longer stops the app opening or reloading offline ([#1698](https://github.com/bobbyquantum/inkweld/pull/1698)).
- About → Changelog shows the latest releases, even in browsers that had cached an old copy ([#1697](https://github.com/bobbyquantum/inkweld/pull/1697)).

There’s nothing to migrate: it upgrades by itself.

The [release notes](https://github.com/bobbyquantum/inkweld/releases) have the full list, and they now thank first-time contributors too. pixo2000 is the first name on there.

You can try it at [inkweld.app](https://inkweld.app), or run it yourself with Docker (`ghcr.io/bobbyquantum/inkweld:beta`). If something breaks, please [open an issue](https://github.com/bobbyquantum/inkweld/issues).
